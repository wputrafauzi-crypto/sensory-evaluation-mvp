# Sensory Evaluation MVP Demo

Static HTML/CSS/JavaScript demo for GitHub Pages. Uses dummy data only; no SharePoint connection or real authentication.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub, for example `sensory-evaluation-mvp`.
2. Upload `index.html`, `.nojekyll`, and `README.md` to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment to finish. The public URL will be:
   `https://YOUR-GITHUB-USERNAME.github.io/sensory-evaluation-mvp/`

## Important

- This is a public demo. Anyone with the URL can access it.
- Do not add confidential or real employee/customer/production data.
- Changes are held only in the current browser session and reset on refresh.
- This prototype is not connected to SharePoint and the login is a visual simulation only.
